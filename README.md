# passwordgenerator
Python script that always generates a strong and secure password.

# When is a password strong?
A strong password is at least 12 characters long, and contains a combination of uppercase letters, lowercase letters, numbers, and symbols. The password can not contain a word that can be found in a dictionary or be the name of a person, character, product, or organization.

# How to run?
Navigate to the script and run the following command.
```
python main.py
```

## Example
When executing the script the program will ask you to enter how long you want the password to be.
```
Enter length of password (<=12 characters)
```
You can enter any length, as long as it is larger or equal than 12.
